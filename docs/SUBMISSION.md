# Цифровой деканат · комплект для жюри

## Комментарий капитана

«Цифровой деканат» помогает студенту найти перенесённую пару и заказать справку. Войдите как студент А, откройте перенос линейной алгебры в разделе «Сегодня» и проверьте новую аудиторию. Затем закажите справку и запомните номер. Войдите как студент Б и сравните профиль, успеваемость и список заявок. В кабинете используются вымышленные данные.

| Поле для подачи | Значение |
|---|---|
| Сайт | ☐ Вставить проверенную публичную HTTPS-ссылку |
| Исходники | [Проверенная версия bd5245b](https://github.com/roma20ix/digital-dean/tree/bd5245b) |
| Отчёт | ☐ Вставить ссылку на утверждённый документ для жюри. [Черновик со снимками](evidence/RELEASE/report.md) |
| Видео, по желанию | ☐ Вставить ссылку при наличии или убрать строку |
| Логин студента А | student_a |
| Логин студента Б | student_b |

Капитан добавляет два разных пароля к логинам непосредственно в закрытом комментарии организатора. В репозитории хранятся только логины.

## Перед публикацией

На 20 ноября 2026 года команда ещё выбирает хостинг. Локальная репетиция завершена. Результаты проверки конфигурации, статики и сохранения данных описаны в [протоколе RELEASE](evidence/RELEASE/check.md).

Капитан либо агент с отдельным разрешением подключает согласованный домен, HTTPS-прокси и постоянную PostgreSQL. Команды сборки, миграции и запуска приведены в [инструкции проекта](../README.md#первый-https-деплой-на-linux). После выпуска создайте справку из кабинета А и запишите номер. Повторно разверните приложение с той же БД и секретами, войдите в новом сеансе, откройте тот же номер и статус. Проверьте также оба входа, загрузку CSS и ответ публичного /health/. Запишите URL, коммит, дату и результат в протокол.
