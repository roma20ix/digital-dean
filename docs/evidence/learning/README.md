# Проверка учебного кабинета

Запустите миграции и `seed_demo` с паролями двух студентов. У каждого пять дисциплин. Основной курс содержит две темы, четыре работы и один короткий ролик. Вторая дисциплина со сроком сдачи содержит задание по подтверждению экзамена. Остальные дисциплины видны в каталоге со своими категориями и текущим результатом.

| После первого заполнения | student_a · ЭК-21 | student_b · ЮР-11 |
|---|---|---|
| Основной курс | Линейная алгебра | Гражданское право |
| Домашнее задание первой недели | Сдать задачи по алгебре | Сдать разбор судебного дела |
| Срок первой работы, Москва | 20 ноября 2026, 18:00 | 24 ноября 2026, 18:00 |
| Оценённая работа | Сложение перемещений, 9/10 | Стороны соглашения, 8/10 |
| Прогресс по основному курсу | 9 из 40 баллов → 2,25 из 10 | 8 из 40 баллов → 2 из 10 |
| Следующая открытая работа этого курса | Проверка преобразования, 26 ноября в 18:00 | Акт приёмки, 26 ноября в 18:00 |

**Короткий маршрут на телефоне.** Войти под `student_b` → «Меню» → «Учёба» → «Гражданское право» → раскрыть первую неделю → «Сдать разбор судебного дела». Ввести ответ, сохранить черновик, затем открыть его через «Мои задания». До 24 ноября, 18:00 по Москве, работу можно сдвинуть на сутки. Проверьте ту же дату в уведомлении. Отправьте решение на проверку и обновите страницу.

Автоматические сценарии запускаются из окружения проекта. Серверные тесты используют временную БД и вымышленные аккаунты. Браузерный тест фиксирует дату 20 ноября 2026, 09:00 по Москве, и проверяет в Chromium обоих студентов при 360 × 740 и 1280 × 800. Он проходит ссылку на работу с «Сегодня», из темы, списка и уведомления, проверяет ближайший дедлайн курса, воспроизведение видео, фильтры и ширину страниц. На настольном экране также выполняются перенос, сохранение черновика и отправка.

```sh
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py migrate --noinput
python manage.py test cabinet
python -m pip install playwright==1.62.0
python -m playwright install chromium
python manage.py test tests.ui.mobile tests.ui.academic tests.ui.academic_a2 tests.ui.learning
```

Если Chromium уже установлен в системе, путь к нему можно указать в переменной `CHROMIUM_PATH`. Переменная `LEARNING_SCREEN_DIR` включает сохранение снимков четырёх учебных экранов для каждого аккаунта и размера.

Решения вводятся текстом. Экран преподавателя для проверки работ в эту версию не входит. Оценённые примеры загружаются с демоданными. Чат курса обновляется при открытии страницы или отправке сообщения. Даты фиксированы для конкурса, поэтому после ноября демонстрационные сроки переходят в прошлое.
