## Повторить проверку

Из корня репозитория в окружении с зависимостями проекта и Python Playwright. Для установленного системного Chromium задайте `CHROMIUM_PATH=/usr/bin/chromium`, иначе установите браузер командой `python -m playwright install chromium`.

- На ветке B2: `python manage.py test tests.ui.academic cabinet` — прошли 11 тестов.
- В рабочей копии с A2 и B2: `B2_SCREEN_DIR=docs/evidence/B2 python manage.py test tests.ui.academic_a2 tests.ui.academic cabinet` — прошли 18 тестов. Без переменной B2_SCREEN_DIR снимки не записываются.

Маршрут вручную: войти как student_a → Уведомления → «Перенос занятия „Линейная алгебра“» → Неделя → Учёба. Для проверки пустого воскресенья открыть /schedule/?mode=day&date=2026-11-22 и перейти по ссылке «Ближайший учебный день с занятиями».
