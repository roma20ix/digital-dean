# B1 · Проверка мобильного кабинета

20 ноября 2026 года, Chromium 156, окно 360 × 740 CSS px, Django 5.2.19. База ветки — main после слияния 00B (dec1e60). Оба эскиза вошли в main. Решение участников в 00B пока не записано. На экране с переносом временно применена иерархия Б.

## Маршрут команды

1. Открыть /login/ и войти своим демоаккаунтом. В меню открыть «Профиль» и сверить ФИО, факультет, направление, курс и группу.
2. В меню выбрать «Сегодня», затем «Заказать справку». Оставить тип «Справка об обучении» и нажать «Отправить заявку».
3. На карточке сверить номер, дату, статус «Принята» и следующий шаг. Через меню вернуться на «Сегодня» и открыть тот же номер под надписью «Последняя заявка».
4. Перейти по ссылке «Мои заявки» → «Новая заявка». Выбрать «Обращение в деканат» и отправить с пустым сообщением. Ввести текст под отмеченным полем и отправить повторно.

## Воспроизведение

Из корня репозитория, в отдельном виртуальном окружении с зависимостями проекта:

```sh
python -m pip install -r requirements.txt playwright==1.62.0
python -m playwright install chromium
python manage.py test tests.ui.mobile cabinet
```

При наличии системного Chromium можно пропустить установку браузера и указать путь к нему. Команда, выполненная в рабочей среде:

```sh
cd /workspace/digital-dean
PYTHONPATH=/workspace/digital-dean-venv/lib/python3.12/site-packages CHROMIUM_PATH=/usr/bin/chromium python manage.py test tests.ui.mobile cabinet
```

Прошли 12 тестов. Два браузерных теста находятся в tests/ui/mobile.py. Переходы и отправка проверены клавишами Tab и Enter с проверкой видимой обводки фокуса. Проверены неверный пароль, возврат на запрошенный профиль, длинное ФИО, пустой и заполненный списки, создание справки и обращения. При отклонённом сервером токене введённый текст сохранился. Все шесть экранов уместились по ширине 360 px.

Путь заявки проверен через настоящие Django-представления на отдельной тестовой БД. A1 пока возвращает пустые занятия, сроки и изменения. Заполненная карточка переноса, ссылка на занятие и срок проверены рендерингом шаблона с тестовыми данными.
