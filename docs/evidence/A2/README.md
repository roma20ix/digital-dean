# Данные A2 для проверки интерфейса

После `python manage.py migrate` выполните `python manage.py seed_demo` с двумя паролями из окружения. Все даты ниже относятся к 2026 году, время московское. Экраны расписания, учёбы и сообщений использует задача B2.

| Что открыть | student_a · ЭК-21 | student_b · ЮР-11 |
|---|---|---|
| «Сегодня» → «Изменения», затем то же сообщение в ленте | 20 ноября, линейная алгебра, Анна Соколова, 10:40–12:10. Аудитория перенесена из 304 в 218 | 23 ноября, гражданское право, Мария Громова, 13:20–14:50. Аудитория перенесена из 107 в 312 |
| День 20 ноября | Три пары. Первая — линейная алгебра в аудитории 218 | Занятий нет. Переход к ближайшему дню открывает 21 ноября, «Теория государства», 13:20, аудитория 204 |
| Неделя при выбранной дате 23 ноября | Пн, ср, пт и сб с занятиями | Пн, вт, чт и сб с занятиями. Понедельник содержит перенос |
| «Учёба» | Линейная алгебра — 5, академическое письмо — зачтено, по статистике оценки пока нет. Экзамен по статистике 2 декабря в 10:00, аудитория 310 | Гражданское право — 4, юридическая риторика — зачтено, по истории права оценки пока нет. Экзамен по истории права 4 декабря в 10:00, аудитория 405 |
| Ближайший срок утром 20 ноября | Сдать задачи по алгебре до 20 ноября, 18:00 | Сдать разбор судебного дела до 24 ноября, 18:00 |

Оба перехода из сообщения о переносе открывают `/schedule/?mode=day&date=YYYY-MM-DD#lesson-ID`. Карточке в шаблоне нужен `id="lesson-{{ lesson.id }}"`. Числовой ID назначает база. Сверяйте дату, предмет и аудиторию. Источник сообщения — «Учебная часть».

«Сегодня» использует текущее московское время. Завершившуюся пару сменяет следующая, а прошедший срок — напоминание о записи на экзамен до 30 ноября, 18:00. Перенос остаётся в «Изменениях» и в расписании на исходную дату. Для проверки воскресенья откройте 22 ноября. У обеих групп следующий учебный день — понедельник 23 ноября. Демо покрывает две недели с 16 по 29 ноября и занятия в начале следующей недели.

В ленте обоих студентов есть «Часы приёма деканата». Отметьте объявление прочитанным у одного, войдите под вторым и проверьте его собственную отметку. Повторная загрузка демоданных сохраняет прочтение и ссылки на занятия.
