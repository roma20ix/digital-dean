## Регрессии и фильтрация данных

Проверка модели доступа проходила на собственных синтетических фикстурах проекта. В `cabinet/test_requests.py` проверены владелец профиля и заявок, чужая карточка, выход и повторный вход. В `cabinet/test_academics.py` проверены группа, индивидуальная успеваемость, получатель уведомления и смена группы. В `cabinet/tests.py` проверены анонимный доступ, завершение сессии, запрет кеширования закрытых страниц и CSRF.

В [представлениях проверенного коммита](https://github.com/roma20ix/digital-dean/blob/5b4befd/cabinet/views.py) профиль выбирается по текущему пользователю. У списка, главной и карточки заявки ограничение по владельцу, а при создании владелец берётся из сессии. Занятия отбираются по группе профиля. Оценки и экзамены ограничены курсами студента. Для чтения ленты и записи признака прочтения применяется один фильтр получателя и группы перенесённого занятия.

## Какие проверки выполнены

Из корня проекта в окружении с зависимостями из `requirements.txt` и Python Playwright 1.62.0:

```sh
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py test
CHROMIUM_PATH=/usr/bin/chromium python manage.py test cabinet tests.ui.mobile tests.ui.academic tests.ui.academic_a2 -v 2
```

Конфигурация чистая, миграции актуальны. SQLite — 16 серверных тестов и 4 явно подключённых UI-теста, все прошли. В проектных UI-тестах проверены клавиатурное управление и крайние состояния. В интеграционном тесте воскресенья часы установлены на 22 ноября. На локальной PostgreSQL 16 также прошли все 16 серверных тестов (HTTP-клиент Django с тестовым отключением HTTPS-редиректа). Для проверенной main успешно завершились задания на Windows и Ubuntu. [CI main](https://github.com/roma20ix/digital-dean/actions/runs/44723876782)

Сквозной проход поверх Gunicorn выполнялся отдельно с настоящими формами входа обоих демостудентов и фактическим московским временем. На каждом размере проверены профиль, перенос с главной и из ленты, неделя, учёба, отправка справки и обращения, возврат к заявке из своего списка после выхода. После перезапуска проверены те же номера в новых сеансах. Номера в таблице принадлежат изолированной базе этого прогона. В `check --deploy` остались два ранее описанных предупреждения HSTS (W005, W021).

1. Войти как A. В «Сегодня» открыть сообщение о переносе линейной алгебры и назвать новую аудиторию — **218**.
