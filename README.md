# Цифровой деканат

Конкурсный личный кабинет студента для MGIMO AI Challenge. Сервер поддерживает вход, профиль, заказ справки и обращение в деканат по [контракту](docs/CONTRACT.md). Для каждого студента доступны собственные заявки и их статусы. Команда `seed_demo` также заполняет расписание, результаты учёбы, уведомления, курсы и задания. Даты и ожидаемые значения для проверки интерфейса приведены в [сценариях A2](docs/evidence/A2/README.md).

## Локальный запуск на Windows

Для каждого участника нужен **один клон репозитория**. В папке рядом с `manage.py` создайте `.env.local` с двумя разными паролями. Если они уже указаны в `.env`, новый файл не нужен. Для кабинета преподавателя можно добавить третью строку. Файлы `.env` и `.env.local` исключены из Git.

```text
DEMO_STUDENT_A_PASSWORD=<ваш пароль для student_a>
DEMO_STUDENT_B_PASSWORD=<другой пароль для student_b>
DEMO_TEACHER_PASSWORD=<третий пароль для teacher_a>
```

Для первого и каждого следующего запуска откройте PowerShell в папке проекта и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\dev.ps1
```

Скрипт создаёт `.venv` при первом запуске, обновляет зависимости при изменении `requirements.txt`, применяет новые миграции, дополняет демоданные и запускает сайт на `http://127.0.0.1:8001/`. Он использует локальную SQLite `db.sqlite3`, где сохраняются созданные заявки и настройки профиля. Остановите сервер через `Ctrl+C`. Для подготовки без запуска сервера используйте `powershell -ExecutionPolicy Bypass -File .\scripts\dev.ps1 -NoServer`.

Чтобы получить свежие изменения **текущей ветки**, остановите сервер и выполните:

```powershell
git pull --ff-only
powershell -ExecutionPolicy Bypass -File .\scripts\dev.ps1
```

При переходе на другую ветку выполните `git fetch origin`, затем `git switch <имя-ветки>` и ту же команду запуска. После объединения изменений в основную ветку выполните `git switch main` и `git pull --ff-only`. Проверьте выбранную ветку командой `git branch --show-current`. Если Git сообщает о локальных изменениях, сначала сохраните их коммитом или отдельно, прежде чем переключать ветку.

Пароли из файла используются скриптом для подготовки демоаккаунтов: при каждом запуске `seed_demo` выставляет их для `student_a`, `student_b` и, если задан третий пароль, `teacher_a`. Приложение само `.env` не читает. Скрипт не выполняет `git pull`, поэтому файлы вашего клона обновляются только после вашей команды Git.

## Первый HTTPS-деплой на Linux

Для краткосрочного конкурса подготовлен [пошаговый запуск на Amvera](docs/DEPLOY_AMVERA.md) с готовым `amvera.yml`. Общая инструкция ниже подходит другим Linux-хостингам.

1. Подготовьте Python 3.12, постоянную PostgreSQL 16 и выделенный домен с TLS. Направьте трафик через прокси хостинга. Он должен сохранять исходный Host, заменять входящий X-Forwarded-Proto фактической схемой и быть единственной точкой доступа к Gunicorn.
2. В панели хостинга задайте переменные для сборки, миграций и процесса приложения. Имена перечислены в [.env.example](.env.example). Django читает переменные процесса. Укажите `DJANGO_SETTINGS_MODULE=config.settings.production`, точные домены через запятую в `DJANGO_ALLOWED_HOSTS` и постоянный случайный `DJANGO_SECRET_KEY`. Ключ можно получить в приватной консоли командой `python -c "import secrets; print(secrets.token_urlsafe(64))"`.
3. Задайте `PGDATABASE`, `PGUSER`, `PGPASSWORD`, `PGHOST` по данным хостинга. Порт PostgreSQL по умолчанию 5432. По умолчанию соединение требует TLS. Если провайдер выдаёт корневой сертификат, установите его для libpq и задайте `PGSSLMODE=verify-full`. Переменная `PORT` задаёт внутренний порт приложения.
4. В виртуальном окружении хостинга выполните сборку и проверку. Миграции запускайте один раз на выпуск до старта новых процессов.

```sh
python -m pip install -r requirements.txt
python manage.py check --deploy
python manage.py collectstatic --noinput
python manage.py migrate --noinput
gunicorn config.wsgi:application --bind "0.0.0.0:${PORT}"
```

5. Откройте публичный `https://<домен>/health/` и проверьте ответ `ok`, переход с HTTP на HTTPS, вход через браузер и загрузку `/static/cabinet.css`. После перезапуска проверьте вход того же пользователя. WhiteNoise раздаёт собранную статику.

Политика HSTS действует на выбранном хосте один час. Предупреждения Django `security.W005` и `security.W021` относятся к распространению HSTS на поддомены и включению preload. Эти параметры требуют отдельного решения владельца домена.

## Проверки

`python manage.py test cabinet.tests.FoundationTests.test_public_health` проверяет публичный ответ отдельно. Полный набор запускается через `python manage.py test`. GitHub Actions проверяет конфигурацию, миграции и тесты на Linux и Windows. На Windows workflow также запускает сервер и запрашивает `/health/` из PowerShell.

Источники зависимостей, лицензии и происхождение элементов интерфейса перечислены в [описании компонентов](docs/THIRD_PARTY.md).

### Демо преподавателя и персонализация

Обновив ветку, установите зависимости из requirements.txt и выполните migrate. В том же окружении, где заданы два пароля студентов, задайте третий отдельный секрет DEMO_TEACHER_PASSWORD и запустите seed_demo. Команда подготовит teacher_a с кабинетом преподавателя и привяжет занятия к его аккаунту. Без третьего секрета команда по-прежнему обновляет студенческие данные. Повторный запуск дополняет существующее расписание и сохраняет загруженные аватары и заявки.

В разделе «Профиль» можно установить изображение и вернуться к инициалам. Для конкурса используйте иллюстрации или вымышленные аватары. Изображение хранится в базе в виде квадратной миниатюры JPEG.

### Учебный кабинет

После обновления выполните `python manage.py migrate --noinput` и `python manage.py seed_demo` с теми же секретами студентов. В «Учёбе» откройте «Линейная алгебра» под `student_a` или «Гражданское право» под `student_b`. Раскройте первую неделю, откройте работу и сохраните текстовый черновик. Этот же текст доступен в «Моих заданиях» после повторного входа. Маршруты и проверочные значения приведены в [сценарии учебного кабинета](docs/evidence/learning/README.md).
